# Cipherion — security checklist

2026-10-02. Это результаты ограниченного code review и автоматических тестов, не сертификат безопасности и не завершённый аудит всех endpoints.

## ✅ Проверено автоматическими тестами

- [x] Серверные сессии; пароли проходят scrypt, cookie содержит случайный токен, в БД хранится его SHA-256.
- [x] Права участников, запрет изменения чужих сообщений, чужого чата и приватного файла.
- [x] Подмена клиентских VIP/admin полей не выдаёт серверных прав.
- [x] 2FA и одноразовые recovery codes; повтор TOTP из настройки 2FA отклоняется.
- [x] Промокоды: срок, аудит, ограничения пользователей и повторного применения.
- [x] Приватность профиля, семейные ограничения и доступ AI к разрешённым чатам.
- [x] Push без текста/имени при отключённом предпросмотре (mock-транспорт).
- [x] CSRF Origin: запрос с чужого origin отклоняется.
- [x] Неверный JSON и JSON не-объект возвращают 400.
- [x] Повтор ключа новой отправки с другим телом возвращает 409; fingerprint сохраняется после restart.
- [x] Общие ошибки API не раскрывают stack trace; новый logger пишет только allowlist метаданных.
- [x] Backup проверяет SHA-256 файлов, row counts, integrity и foreign keys; испорченная копия отклоняется.

## ⚠️ Проверить в production/staging

- [ ] COOKIE_SECURE=1, HTTPS, PUBLIC_ORIGIN и доверенная proxy-конфигурация.
- [ ] Все секреты — только env сервера; bucket закрыт; выдача файлов проверяет текущие права.
- [ ] Отключить bootstrap admin claim после первоначального получения прав; проверить список ADMIN_USER_IDS.
- [ ] Ротация ключей, ограничение доступа к backup и encryption at rest.
- [ ] Реальный TURN выдаёт временные credentials и не раскрывает серверный secret.
- [ ] Реальные push subscriptions после logout, смены аккаунта и истечения токена.
- [ ] Ограничения размеров файлов/AI, параллельные загрузки, HTTP timeouts и нагрузка на scrypt.
- [ ] Все служебные/фоновые ошибки проходят безопасный logger; никаких OTP, паролей, cookie и URL БД в логах.
- [ ] Результат аудита зависимостей и настройка обновлений. Установка npm ci не является аудитом уязвимостей.

## ❌ Не завершено

- [ ] Email/phone verification, одноразовые OTP с TTL, лимиты отправки и анти-спам регистрации.
- [ ] Полный endpoint-by-endpoint аудит: каждый HTTP-метод, IDOR/BOLA, разрешения и негативные тесты. Текущие tests покрывают только перечисленные сценарии.
- [ ] Долговечный/распределённый rate limiting; сейчас Map сбрасывается при перезапуске, IP берётся из socket.
- [ ] Миграция секретных данных, прав и связей в постоянную внешнюю БД.
- [ ] Удалённый object storage; комплексная валидация MIME/signatures и управление ссылками/удалением объектов.
- [ ] End-to-end тесты на настоящих устройствах и сетях.

## Области следующего аудита

| Область | Файлы | Что проверять |
|---|---|---|
| Auth, сессии, медиа, звонки | server/index.js, server/security.js | каждый ID, отзыв сессий, Origin/proxy, подтверждение контактов, signal target, перегрузка |
| Чаты, участники, права | server/index.js, server/permissions.js | все роли, запреты после выхода/бана, пересылка, reply, гонки |
| Приватность и профиль | server/privacy.js, server/profiles.js, server/family.js | видимость каждого поля/медиа, исключения, семейные ограничения |
| Push | server/delivery.js, public/sw.js, public/notifications.js | подписка устройства, смена аккаунта, expired tokens, приватный payload |
| VIP и администрация | server/admin.js, server/vip.js, server/promos.js | каждый admin метод, audit, отзыв/истечение, конкурентное использование кода |
| AI | server/ai.js | scope истории, отзыв разрешений во время stream, provider timeout, максимальный контекст |
| Истории, опросы, стикеры | server/stories.js, server/polls.js, server/stickers.js, server/social.js | каждое действие и тип медиа, видимость/архив, парсеры файлов |

В checklist нельзя ставить выполненную отметку только по факту наличия проверки в коде: требуются негативный тест или воспроизводимый результат приёмки.
