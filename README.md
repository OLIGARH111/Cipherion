# Cipherion — полноценный мессенджер без Node.js

Реалтайм-мессенджер на **Python + FastAPI + WebSockets + SQLite**.

## Возможности

- Регистрация и вход
- Личные чаты (1-на-1)
- **Голосовые сообщения** (зажал 🎤 — говоришь — отпустил)
- Статус онлайн/оффлайн
- История сообщений
- Современный тёмный интерфейс
- Работает в реальном времени

---

## Как запустить в VS Code

### 1. Распакуй архив
Распакуй папку `messenger` куда угодно.

### 2. Открой в VS Code
```
File → Open Folder… → выбери папку messenger
```

### 3. Создай виртуальное окружение (рекомендуется)
Открой терминал в VS Code (`Ctrl+`` `) и выполни:

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 4. Запусти сервер

**Самый удобный способ (через отладчик):**
1. Нажми `F5` или открой вкладку **Run and Debug** (Ctrl+Shift+D)
2. Выбери конфигурацию **▶ Запустить Cipherion**
3. Нажми зелёную кнопку Play

**Или через терминал:**
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 5. Открой в браузере
Перейди по адресу:  
**http://localhost:8000**

## Как пользоваться

1. Зарегистрируй **два** аккаунта (в двух разных браузерах / вкладках / режиме инкогнито)
2. В одном аккаунте нажми на пользователя из списка справа
3. Напиши сообщение — оно мгновенно появится у второго

## Примечание

База данных `messenger.db` создаётся автоматически при первом запуске.
Чтобы сбросить всех пользователей — просто удали файл `messenger.db`.

**Если обновляешь со старой версии** (без голосовых) — удали `messenger.db`,
чтобы база пересоздалась с новыми полями.

### Голосовые сообщения

1. Открой чат
2. **Зажми** кнопку 🎤 и говори
3. **Отпусти** — сообщение отправится
4. Нажми ▶ на сообщении, чтобы прослушать

Браузер попросит разрешение на микрофон — разреши.
Голосовые хранятся в папке `uploads/voices/`.
