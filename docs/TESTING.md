# Проверки выпуска

Автоматически:

```sh
node scripts/check.js
node --test tests/*.test.js
```

Проверяются синтаксис всех модулей, реальные HTTP-запросы к временному серверу, регистрация / вход / выход, SSE-доставка, хранение и редактирование сообщений, запрет доступа чужому аккаунту, ACL вложений, голосование, ограничения и блокировки. Тесты используют временную БД и не изменяют данные рабочего экземпляра.

Вручную через браузер проверены: вход тестового аккаунта, создание группы, отправка сообщения, отображение сохранённого сообщения после перезагрузки, desktop-переписка, mobile layout 390×844, переход в настройки и preview светлой темы. Исправлена найденная ошибка переключения `classList.toggle` при неопределённом значении системной темы.

Не проверены физические камера / микрофон, настоящий двусторонний звонок, TURN, Bluetooth / iOS-устройства и внешний провайдер транскрибации. Для приёмки этих функций нужны целевые устройства и конфигурация окружения.

## Ручная приёмка на двух устройствах

1. Запустить HTTPS-экземпляр с TURN, создать два аккаунта.
2. Создать личный чат. Проверить текст, вложения, прочтение и набор текста в обоих направлениях.
3. Записать голос и видео-кружочек, проверить отмену, фиксацию, отправку, скорость и перемотку.
4. Принять и отклонить аудио- / видеозвонок. Проверить mute, камеру, смену устройств, сворачивание, завершение.
5. Поделиться экраном, завершить трансляцию системной кнопкой, проверить остановку захвата при завершении звонка.
6. В группе проверить права с аккаунта участника после изменения владельцем, истечение ограничения и отзыв доступа к медиа после блокировки.
7. Отключить интернет и восстановить. Проверить перечитывание сохранённых сообщений и поведение звонка.
