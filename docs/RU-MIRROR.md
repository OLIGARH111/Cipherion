# Вход без VPN из России

Адрес `cipherion-messenger.onrender.com` работает через Cloudflare, а российские провайдеры его замедляют и обрывают: страница не грузится или висит. Решение — зеркало на российском сервере. Пользователи открывают его адрес, а сервер незаметно пересылает всё на Render. Аккаунты, чаты и база остаются прежними.

## Что понадобится

- Самый дешёвый VPS в России (Timeweb Cloud, Selectel, Beget, REG.RU, Yandex Cloud) с Ubuntu 22.04 или 24.04. Хватит 1 ядра и 1 ГБ памяти, около 200–300 ₽ в месяц.
- Свой домен необязателен: без него адрес будет вида `https://185-12-34-56.sslip.io`. С доменом (например, `.ru`) направьте его A-запись на IP сервера.

## Установка (5 минут)

1. Зайдите на сервер по SSH (в панели хостинга обычно есть кнопка «Консоль»).
2. Выполните:
   ```sh
   git clone https://github.com/OLIGARH111/cipherion.git
   sudo sh cipherion/deploy/ru-mirror/install.sh            # без домена
   # или: sudo sh cipherion/deploy/ru-mirror/install.sh chat.example.ru
   ```
   Скрипт поставит Caddy, сам получит HTTPS-сертификат и напечатает адрес зеркала.
3. На Render: **Environment → Add variable** `MIRROR_ORIGINS` = адрес из шага 2 (например `https://185-12-34-56.sslip.io`). Нажмите **Save, rebuild and deploy**. Несколько зеркал перечисляются через запятую.
4. Откройте адрес зеркала с телефона без VPN.

## Что важно знать

- Без шага 3 вход и отправка сообщений через зеркало вернут ошибку «Недопустимый источник запроса».
- Сессии привязаны к адресу: на зеркале нужно войти заново один раз. Ключи доступа (passkey) тоже создаются для каждого адреса отдельно.
- PWA, push-уведомления и звонки работают так же, как на основном адресе.
- Если Render когда-нибудь начнут блокировать и для серверов в России, весь сервис можно перенести на этот же VPS: `Dockerfile` в корне проекта запускается там без изменений.
