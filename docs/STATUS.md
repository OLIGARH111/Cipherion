# Соответствие расширенному ТЗ

ТЗ описывает большой продукт, включающий сервер, нативные приложения, платежи и ИИ. Версия 0.1.0 реализует рабочий web-контур; следующие границы нельзя считать завершёнными функциями.

| Область | Реализовано | Осталось |
| --- | --- | --- |
| Аккаунт | Username / пароль, имя, bio, аватар, управление сессиями | Телефон, отдельная фамилия, изменение username, MFA, passkey / Face ID, код приложения |
| Сообщения | Реальное хранение и SSE, вложения, ответы, пересылка, редактирование, удаление, статусы, ввод текста | Сквозное шифрование вложений (текст уже шифруется, см. E2E.md), гарантированная офлайн-очередь отправки, реакции, библиотека стикеров и GIF, поиск внутри истории, папки |
| Группы | Серверные роли, права, ограничения со сроком, теги, блокировка, передача владельца, журнал | Темы / треды, пригласительные ссылки, гибкие роли для всех медиакатегорий, отдельные справочники тегов, выбор произвольной даты ограничения |
| Медиа | Файлы, фото, видео, аудио, запись кружочков, фиксация и отмена | Реальный waveform по аудиосигналу, редактирование записанного медиа, серверное перекодирование и превью |
| Опросы | Один / несколько вариантов, смена голоса, счётчики | Викторины, закрытие опроса, отображение личности проголосовавших в неанонимном режиме |
| Звонки | WebRTC mesh до 6 участников, сигналинг, входящий экран, устройства, сворачивание, экран | SFU, гарантированное восстановление при смене сети, активный говорящий, перетаскиваемое self-view, точная длительность от принятия, права демонстрации организатором |
| Связность | ICE-конфигурация, базовый ICE restart | Развёрнутый TURN, измерение качества / custom bitrate policy, тесты на реальных сетях и телефонах |
| Системные функции | Браузерные разрешения и уведомления открытой вкладки | CallKit / Android Telecom, wakeup входящим звонком, native picture-in-picture, фоновые push |
| Оформление | 10 тем, живой preview, фото навигации, настройки стекла и контраста, mobile layout | Физически точная модель рефракции, пружинная перемещающаяся капсула, все индивидуальные фоны панелей, выбор иконки приложения, расширенные параметры бликов |
| Конфиденциальность | Блокировки, HttpOnly-сессии, server ACL | Матрица видимости телефона / online / last seen, настройка входящих сообщений и звонков по категориям контактов |
| Уведомления | Общие и для отдельных чатов, предпросмотр, браузерный запрос разрешения | Независимые звуки, управление вибрацией, категории каналов / групп, push после закрытия |
| Память | Лимит файлов, ручная очистка локальных черновиков | Учёт и очистка server cache, квоты, Wi-Fi / cellular auto-download policy |
| ИИ | Реальный адаптер транскрибации по явному запросу | Подключённый провайдер, диаризация, таймкоды, ассистент, память, перевод, резюме и умные ответы |
| Платежи | Не подключены | Провайдер, подписки, оплата, история, app-store billing |
| Языки | Русский интерфейс | Переводы и автоматическое определение языка |

UI не имитирует наличие неподключённых платежей, нативной биометрии или ИИ. Интеграционные требования требуют отдельных конфигураций / сервисов. Остальные недостающие функции требуют дальнейшей разработки, а не только ключа API.

Базовые звонки реализованы в коде, но двусторонний медиасеанс с физическими устройствами в данной проверке не проведён. Нельзя считать их проверенными в production.
