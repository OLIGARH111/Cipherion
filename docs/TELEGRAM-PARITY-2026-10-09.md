## Схема данных
Изменения аддитивные, существующие записи не трогаются: колонки `members.cleared_at`, `members.hidden`, таблицы `drafts` и `recovery_keys`. Они создаются при старте так же, как в остальных модулях (`PRAGMA table_info` + `ALTER TABLE ADD COLUMN`).

## Ограничения
- Аккаунты, созданные до этого обновления, не получили ключ автоматически: его нужно создать в «Конфиденциальность → Восстановление пароля». Без ключа и без подтверждённого email забытый пароль по-прежнему не восстановить.
- «Удалить для собеседника» скрывает историю у обоих, но сами записи остаются в базе (как и при «удалении для всех» отдельных сообщений).
- Поиск по тексту регистронезависим для первой буквы и целого слова в разных регистрах (`Пятница`/`пятница`/`ПЯТНИЦА`); произвольное смешение регистров SQLite без ICU не сравнивает.
