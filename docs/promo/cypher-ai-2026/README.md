# Промо-ролик «Cypher AI в Cipherion» (ноябрь 2026)

`cipherion-cypher-ai-2026.mp4` — 71 с, 1080×1920, 30 кадров/с. Сделан так же, как ролик Хэллоуина
(`docs/promo/halloween-2026`): сцена `index.html` с 3D-телефоном, кадры снимаются через `window.render(t)`.

Пересобрать: `node docs/promo/cypher-ai-2026/render.mjs [выход.mp4] [--from=сек --to=сек]` (нужны Playwright и ffmpeg).
Открыть `index.html` в браузере — ролик проигрывается по кругу.

Сюжет:
1. Раздел AI в стиле Cypher: HUD, сфера (тот же алгоритм, что `public/cypher-orb.js`), карточки.
2. Чат с Cypher: потоковый ответ по разрешённым чатам и черновик.
3. Подключение Cypher для Windows по коду `ABCD-EFGH` (монитор рядом с телефоном).
4. Управление ПК: Блокнот, команда с текстом, громкость.
5. «Что на экране?».
6. Уведомления о сообщениях на ПК (зашифрованный текст Cypher не видит).
7. Общая память AI.
8. Фото HEIC → JPEG и очередь отправки, где видео не держит остальные.
9. Просмотр фото в стиле iOS.
10. Нижнее меню из жидкого стекла: удержание, состав разделов.
11. «А ещё»: папки, кнопки ботов, перенос истории по QR, звонки до 30 человек, голосовые комнаты, код-пароль.
