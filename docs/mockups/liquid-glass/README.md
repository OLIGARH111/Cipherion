# Cipherion · Liquid Glass — макет

Визуальный макет того, как стеклянные контролы в духе Telegram на iOS 26 могут выглядеть в Cipherion на iOS 18 и старше.

Откройте [`index.html`](./index.html) в браузере.

## Что показано

| Кадр | Поведение |
|---|---|
| Чаты | Таб-бар без блюра фона. Линза блюрит только иконки бара, тянется по скорости, пружинит и увеличивается при нажатии. Текст списка под панелью остаётся резким. |
| Кнопки | Скрепка, микрофон и видео остаются кнопками Cipherion. Жидкое стекло — только эффект нажатия: вспышка, scale-up, растяжение за пальцем, отскок. Удержание микрофона — запись, свайп влево — отмена. |
| Переключатели | Дорожка сплошная. Блюр, блик, увеличение и растяжение только у бегунка тумблера и слайдера. |

Цвет акцента — изумруд Cipherion. Кнопки не заменяются на стеклянные диски Telegram: вливается только эффект.

Это макет интерфейса, не патч исходников Telegram iOS и не включение эффекта в рабочий клиент.
