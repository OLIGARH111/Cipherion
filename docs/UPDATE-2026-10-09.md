# Обновление 9 октября 2026

## Звонки по мобильной сети
Симптом: по Wi‑Fi слышно обоих, по мобильной связи — только одного.

Причины и исправления (`public/calls.js`):
- **Одновременные offer (glare).** Обе стороны сразу добавляли дорожки и отправляли offer. На медленной мобильной сети offer'ы встречались, «вежливая» сторона откатывалась, и часть мобильных браузеров отвечала `recvonly` — звук шёл в одну сторону. Теперь первый offer отправляет только одна сторона, вторая подключает микрофон в ответ на offer (fallback через 6 с).
- **Порядок сигналов.** ICE-кандидаты уходили параллельными POST-запросами и могли обогнать SDP. Теперь сигналы к каждому собеседнику отправляются строго по очереди.
- **ICE restart только с одной стороны** (вторая просит его сигналом `restart`), без гонки двух offer'ов.
- **Сторож входящего звука:** если соединение «connected», но байты аудио от собеседника не растут ~7 с, маршрут пересогласуется.
- `bundlePolicy: max-bundle`, `rtcpMuxPolicy: require`, пул кандидатов.

**TURN.** Операторы мобильной связи используют CGNAT; без TURN-ретранслятора часть звонков в принципе не соединится. Помимо Coturn (`TURN_URLS` + `TURN_SHARED_SECRET`) теперь поддерживаются управляемые TURN:
- Cloudflare Realtime: `CLOUDFLARE_TURN_KEY_ID`, `CLOUDFLARE_TURN_API_TOKEN`;
- Metered: `METERED_TURN_DOMAIN`, `METERED_TURN_API_KEY`.
Временные credentials запрашивает сервер (`server/turn.js`), секрет клиенту не передаётся.

## Стикеры
Три анимированных набора (36 SVG, `scripts/build-aesthetic-stickers.js` → `public/stickers-v3/`): «Облачко Мими», «Аура», «Слова». Анимация — CSS/SMIL внутри SVG, у каждого есть статичный постер `-still.svg` (экономия батареи и `prefers-reduced-motion`). Наборы один раз автоматически добавляются каждому аккаунту; удалённый пользователем набор не возвращается.
