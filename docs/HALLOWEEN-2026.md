# Хэллоуин 2026

Сезонное обновление. Действует с 29 октября по 3 ноября включительно (по московскому времени). Сезон определяет сервер, а для проверки на стенде его можно принудительно включить или выключить переменной `HALLOWEEN=on|off`.

## Что есть
- **Темы «Ночь тыкв» и «Зелье»** остаются доступны и после праздника. Если тема включена из окна «Что нового», после сезона вернётся прежняя.
- **Оформление**: луна и туман на фоне, летучие мыши, баннер над списком чатов, одноразовое окно «Что нового». Всё это выключается в «Настройки → 🎃 Хэллоуин». При «уменьшении движения» анимации нет.
- **Призрачные сообщения** (кнопка 👻 у поля ввода, только личные чаты и группы). Сервер удаляет сообщение через 60 секунд после того, как его прочитал кто-то кроме автора. Такие сообщения нельзя переслать, а в push-уведомлениях их текст не показывается. Получатель может запретить их в настройках.
- **«Сладость или гадость»** (меню 📎). Сыграть может любой участник, кроме автора, только один раз. Исход выбирает сервер случайно.
- **Стикеры «Хэллоуин»**: 12 анимированных SVG (`scripts/build-halloween-stickers.js` → `public/stickers-v5`). Набор автоматически добавляется всем аккаунтам.
- **Рамки профиля** «Тыква», «Слизь», «Призрак», «Ведьма» в VIP-оформлении профиля.

## База данных
К таблице `messages` при старте добавляются колонки `ghost`, `ghost_until` и `game`. Изменение только добавляет данные, существующие записи не меняются.
