# Cipherion для iPhone — звонки через CallKit

Нативное приложение-оболочка вокруг веб-версии Cipherion. Главное, что оно даёт —
**входящие звонки на системном экране iPhone**, как у обычного телефонного звонка:

- звонок приходит, даже если Cipherion закрыт, свёрнут или телефон заблокирован;
- полноэкранный вызов на экране блокировки, кнопки «Принять» / «Отклонить»;
- звонки видны в «Недавних» приложения «Телефон», работают кнопки гарнитуры и CarPlay;
- «Принять» сразу подключает разговор в Cipherion, «Отбой» и «Без звука» на системном экране работают;
- если вы ответили на другом устройстве или собеседник положил трубку, iPhone перестаёт звонить;
- уведомления о сообщениях тоже приходят через Apple (в WebView веб-пуши недоступны).

Веб-версия (PWA) этого сделать не может: Apple даёт CallKit и VoIP-пуши только нативным приложениям.

## Как это работает

1. Приложение регистрируется в PushKit и получает VoIP-токен устройства.
2. Страница Cipherion внутри приложения отправляет токен на сервер (`POST /api/push/native`) —
   для всех аккаунтов, в которые вы вошли.
3. Когда вам звонят, сервер отправляет VoIP-пуш в Apple (APNs). iOS будит приложение,
   и оно сразу показывает системный экран звонка (CallKit).
4. «Принять» → приложение открывает чат и подключается к звонку WebRTC.
5. Звонок закончился / принят на другом устройстве → сервер шлёт пуш `end`, iPhone замолкает.

Файлы: `Cipherion/CallManager.swift` (CallKit), `Cipherion/AppDelegate.swift` (PushKit и уведомления),
`Cipherion/WebViewController.swift` (веб-версия и мост к ней), на сервере — `server/apns.js`,
в веб-части — `public/native-bridge.js`.

## Что нужно сделать (один раз)

Нужны Mac с Xcode 16+ и платный аккаунт Apple Developer ($99/год) — без него VoIP-пуши не работают.

### 1. Ключ APNs для сервера

1. developer.apple.com → Certificates, IDs & Profiles → **Keys** → «+».
2. Отметьте **Apple Push Notifications service (APNs)**, сохраните и скачайте файл `AuthKey_XXXXXXXXXX.p8`
   (скачать можно только один раз).
3. В Render → сервис cipherion → Environment добавьте:
   - `APNS_KEY_ID` — 10 символов из имени ключа;
   - `APNS_TEAM_ID` — Team ID (developer.apple.com → Membership);
   - `APNS_PRIVATE_KEY` — всё содержимое файла `.p8`;
   - `APNS_BUNDLE_ID` — `com.cipherion.app` (или ваш, если поменяете ниже).
4. После деплоя `/health` покажет `"nativePushConfigured": true`.

### 2. Сборка приложения

```sh
brew install xcodegen
cd ios
xcodegen            # создаёт Cipherion.xcodeproj
open Cipherion.xcodeproj
```

В Xcode: target **Cipherion** → Signing & Capabilities → выберите свою Team.
Если `com.cipherion.app` занят, поменяйте Bundle Identifier (и `APNS_BUNDLE_ID` на сервере).
Возможности Push Notifications и Background Modes (Voice over IP, Audio) уже прописаны.

Адрес сервера — ключ `CipherionServerURL` в `Cipherion/Info.plist`
(сейчас `https://cipherion-messenger.onrender.com`).

### 3. Установка

- На свой iPhone: подключите телефон, выберите его в Xcode, нажмите ▶︎.
  Сборка из Xcode использует «песочницу» APNs — сервер это учитывает автоматически.
- Для других людей: Product → Archive → TestFlight / App Store.

## Проверка

1. Откройте приложение, войдите, разрешите уведомления, микрофон и камеру.
2. Закройте приложение (смахните из списка) и заблокируйте телефон.
3. Позвоните себе с другого устройства — должен появиться системный экран звонка.
4. Примите вызов — разговор подключается; проверьте «Без звука» и «Отбой».
5. Позвоните ещё раз и ответьте на компьютере — iPhone должен перестать звонить.

## Ограничения

- Код не проверен на физическом iPhone — здесь его не на чем запустить. Сборку проверяет GitHub Actions
  (`.github/workflows/ios.yml`), а работу звонков нужно проверить на устройстве по шагам выше.
- Если ответить с экрана блокировки, iOS может не дать странице включить микрофон, пока приложение
  в фоне. Тогда нажмите кнопку Cipherion на экране звонка — звук пойдёт, когда приложение откроется.
- Звонок звонит 45 секунд, как и в веб-версии.
- Если в настройках уведомлений Cipherion выключены «Звонки», VoIP-пуши не отправляются.
