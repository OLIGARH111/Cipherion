# Промо-ролик: видео-кружочки

`round-video.mp4` — вертикальный ролик 1080×1920, 30 fps, 27 секунд, без звука (подписи на экране).

Сцены повторяют то, как кружочки устроены в приложении (`public/round-video.js`, `public/tg-update.css`, запись в `public/app.js`):

1. Заставка.
2. Тап по кнопке записи — микрофон сменяется камерой, тост «Режим видео-кружочка».
3. Удержание — окно записи: зеркальное превью, кольцо прогресса, таймер, подсказка «Отпустите, чтобы отправить · Влево — отмена · Вверх — закрепить»; свайп вверх закрепляет запись.
4. Отправка — кружок появляется в чате (беззвучное превью, длительность, значок без звука).
5. Тап — кружок растёт прямо в чате и играет с кольцом прогресса; тап по краю — перемотка, в центр — пауза.
6. «Расшифровать» — текст кружочка.
7. Финал: запись до 3 минут (с VIP — до 10).

## Пересобрать

`scene.html` рисует каждый кадр как чистую функцию времени (`window.frame(t)`), а `record.mjs` проходит по кадрам в Chromium и кодирует их через ffmpeg:

```sh
npm i --no-save playwright   # если Playwright не установлен
node promo/round-video/record.mjs            # → promo/round-video/round-video.mp4
node promo/round-video/record.mjs out.mp4 --fps 60
```

Посмотреть анимацию вживую — открыть `scene.html` через любой локальный сервер из корня репозитория; `?t=12.5` показывает один кадр.
